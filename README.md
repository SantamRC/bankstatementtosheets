# BankStatementToSheets.com

Convert PDF bank statements to Excel, CSV and Google Sheets — every row verified against the statement's running balance.

```bash
cp .env.example .env.local   # set ANTHROPIC_API_KEY (Supabase/Stripe/Google optional for local dev)
npm install
npm run dev
npm test
```
